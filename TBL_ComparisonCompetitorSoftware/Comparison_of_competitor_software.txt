PHYLOSUITE (ZHANG D. ET AL. 2019)
https://doi.org/10.1111/1755-0998.13096
https://github.com/dongzhang0725/PhyloSuite
########################################################################

PROGRAMMING LANGUAGE(S):
Python 3; GUI implemented using PyQt5

GENERAL SOFTWARE STRUCTURE:
- GUI-based workflow platform that coordinates a collection of external bioinformatics programs through predefined graphical workflows
- Provides predefined settings for six locus types: Mitogenome, Chloroplast Genome, General, cox1, 16S, and 18S.

STANDARDIZATION OF GENE NAMES:
- Standardizes sequence annotations, including gene names using user-specified lookup tables ('Names unification table'; a CSV-file) - therefore relies heavily on prior knowledge
- Provides an editing window that reports annotation errors and warnings, including missing genes and non-standardized annotations.
- NOTE: Editing window works on mitogenome datasets only! (Why? The project evolved directly from MitoTool, which was specifically developed for mitochondrial genome analyses. The code base still contains many mitochondria-oriented assumptions.)
- Restricts extraction to features listed in the 'Names unification table' via option 'Only extract these genes'
- Novel annotation variants are not automatically recognized.

EXTRACTION OF DNA SEQUENCES:
- Done via tool 'Extract GenBank file (EGBF)', which parses various file formats, including GenBank flatfile, FASTA, NEXUS, PHYLIP, PAML, etc.
- Extracts coding sequences (CDS) by default.
- Supports recognition of non-coding regions through the 'Set NCR threshold' option, allowing users to define a minimum NCR length for subsequent extraction.
- NOTE: NCR threshold does not work with our dataset. (Why? The project evolved directly from MitoTool, which was specifically developed for mitochondrial genome analyses. The code base still contains many mitochondria-oriented assumptions.) [CHECK IF THIS IS CORRECT!]
- Identifies and removes duplicated sequences using the 'Highlight Identical Sequences' function.
- Extracts CDS features into separate output folders containing amino acid sequences ('CDS_AA') and nucleotide sequences ('CDS_NUC').
- In the Mitogenome workflow only, generates a 'self-translated_AA' folder containing amino acid sequences translated from CDS nucleotide sequences.

ACCOUNTING FOR GENE DUPLICATION (E.G., IRs):
- Duplicate detection is annotation-based rather than sequence-based: The software simply detects repeated annotation labels.
- Detects duplicated genes within individual records and appends copy numbers according to occurrence order.
- Supports automatic removal of duplicated genes through the 'Resolve gene duplicates' function.

ALIGNMENT OF DNA SEQUENCES:
- Done via tool 'MAFFT'; is a simple wrapper around MAFFT
- Alignment procedures are delegated to these aligners and therefore inherit its computational limitations
- Refines alignments in batch mode using MACSE (tool 'MACSE')
- Optimizes ambiguously aligned regions using tool 'Trimming' (wrapper for trimAl, HmmCleaner, or Gblocks).
- Concatenates multiple alignments and generates partition files for downstream phylogenetic analyses.

ENABLES GENE ALIGNMENT BASED ON AAs:
- Supports three MAFFT alignment modes: 
	* Normal mode: aligns input sequences directly.
	* Codon mode: translates CDS nucleotide sequences into amino acids, aligns them, and back-translates the resulting alignment into codons.
	* N2P mode: translates CDS nucleotide sequences into amino acids and outputs amino acid alignments without back-translation.

OTHER FEATURES:
- Automates phylogenetic workflows through the 'Flowchart' function:
	* Integrates model selection (ModelFinder, PartitionFinder) and phylogenetic tree reconstruction (MrBayes, IQ-TREE).

RUNTIME DURATION:
[INFORMATION MISSING!]

MPI IMPLEMENTATION:
- No native MPI implementation
- MPI support may be present in some third-party tools (e.g., MAFFT)

MAIN RESTRICTIONS:
- No automated handling of plastome-specific annotation idiosyncrasies (IR presence).
- No native MPI implementation
- Strong dependence on GenBank annotation quality and consistence, as frame shifts or premature stop codons not adjusted for
- GUI-centered architecture limits reproducibility and prevents integration into HPC pipelines or workflow managers (e.g., Nextflow)
- Due to heavy reliance on third-party software, many functions become unavailable if these dependencies are missing or misconfigured.

OGU (WU ET AL. 2024)
https://doi.org/10.1111/1755-0998.14044
https://github.com/wpwupingwp/OGU
########################################################################

PROGRAMMING LANGUAGE(S):
Python 3; GUI implemented using PySide6

GENERAL SOFTWARE STRUCTURE:
- Can be used via both GUI and command-line
- Consists of three modules (GB2FASTA, Evaluate, and Primer) plus some visualization functions.
- Modules can be executed independently or in combination.

STANDARDIZATION OF GENE NAMES:
- Standardizes inconsistent GenBank feature names through the '-rename' option.
- Performs annotation checking and sequence validation

EXTRACTION OF DNA SEQUENCES:
- Done via module 'GB2fasta'
- Extracts coding and non-coding genomic regions, including CDS, introns, and intergenic spacers.
- Extracts sequences on a per-locus basis and generates one output file per locus.
- Extracts intergenic spacers based on annotations of flanking features (i.e., even if spacers not explicitly annotated).
- Tested on datasets of different sizes (mostly smaller than complete genomes), plastid genomic data from the Lamiaceae, mitochondrial data from rodents, and 308 complete plastid genomes across angiosperms

ACCOUNTING FOR GENE DUPLICATION (E.G., IRs):
- Supports handling of repeat regions:
	* Retains only the longest duplicate locus by default.
	* Retains all duplicate loci with '-allow_repeat'.
	* Standardizes inverted-repeat locus names with '-allow_invert_repeat'.
- Retains only complete loci at inverted-repeat boundaries.
- Removes redundant sequences.
- Retains a single representative sequence per organism and locus by default.

ALIGNMENT OF DNA SEQUENCES:
- Done via tool 'Evaluate', which is a wrapper exclusively around MAFFT
- Default execution uses MAFFT v7.475 with the '–auto' option.
- No alternative alignment software options implemented [CHECK IF THIS IS CORRECT!]

ENABLES GENE ALIGNMENT BASED ON AAs:
- performs extraction and alignment only on nucleotide-level 
- no indication for implementation of codon-aware AA-guided alignments

OTHER FEATURES:
- Automated visualization of sequence variability across organellar genomes
- Identification of candidate barcode regions
- Automated primer design using the module 'Primer' based on variability analyses

INPUT DATA LIMITATIONS:
- Authors have successfully tested dataset of 308 complete plastid genomes across angiosperms

RUNTIME DURATION:
[INFORMATION MISSING!]

MPI IMPLEMENTATION:
- No native MPI implementation
- MPI support may be present in some third-party tools (e.g., MAFFT)

MAIN RESTRICTIONS:
- No native MPI implementation
- No support for alignment software other than MAFFT [CHECK IF THIS IS CORRECT!]
- No description of AA-guided nucleotide alignment

PARTITIONING_EXONS_INTRONS_SPACERS (DE MESTIER ET AL. 2025)
https://doi.org/10.1093/aob/mcaf148
https://github.com/sannalda/PartitioningExonsIntronsSpacers
########################################################################

PROGRAMMING LANGUAGE(S):
Python (primarily Python 2, only partial compatibility with Python 3)

GENERAL SOFTWARE STRUCTURE:
- Single script that processes one annotated plastid genome at a time and partitions it into exon, intron, and intergenic spacer datasets

STANDARDIZATION OF GENE NAMES:
- Implements extensive hard-coded normalization of plastid gene names; relies on predefined naming rules
- Merges alternative annotation spellings and naming conventions into standardized locus names.

EXTRACTION OF DNA SEQUENCES:
- Extracts exons, introns, and intergenic spacers from annotated genomes.
- Validates coding sequences using start-codon, stop-codon, internal-stop-codon, and reading-frame checks.
- Searches up to 50 bp upstream and downstream for alternative start and stop codons when validation criteria are not met.
- Supports automated correction of selected start-codon, stop-codon, and reading-frame inconsistencies.
- Does not extract rRNA and tRNA datasets as part of its automated workflow
- Assumes full gene synteny
- Problematic loci and associated introns or spacers are not removed automatically and require downstream manual curation

ACCOUNTING FOR GENE DUPLICATION (E.G., IRs):
- Extracts loci from a single inverted-repeat region to avoid duplicate sampling.

ALIGNMENT OF DNA SEQUENCES:
- Does not provide wrappers or connectors to any alignment software

ENABLES GENE ALIGNMENT BASED ON AAs:
- No

OTHER FEATURES:
- None.

INPUT DATA LIMITATIONS:
[INFORMATION MISSING!]

RUNTIME DURATION:
[INFORMATION MISSING!]

MPI IMPLEMENTATION:
- No

MAIN RESTRICTIONS:
- Processes only one genome at a time (no true batch processing)
- Requires manual curation of extracted loci
- No automatic multiple sequence alignment
- No native MPI implementation
- No integrated workflow beyond sequence extraction
- No scalability features for large numbers of input genomes

PLASTIDHUB (ZHANG N.-N. ET AL. 2025)
https://doi.org/10.1016/j.pld.2025.05.005
https://github.com/quxiaojian/PlastidHub
########################################################################

PROGRAMMING LANGUAGE(S)/IMPLEMENTATION:
Vue 3 + Element Plus (frontend), Spring Boot 3.3.2 (backend), Perl 5.26.1 (analysis scripts), RabbitMQ (message queue), and Redis (status management)

GENERAL SOFTWARE STRUCTURE:
- Browser-based web application for plastome analysis
- Uses server-side rather than local execution
- User interaction through static and dynamic pop-up interfaces
- Supports batch processing across all tools
- Supports modular workflows in which applications can be executed independently or in combination

STANDARDIZATION OF GENE NAMES:
- Evaluates sequence annotation consistency and completeness for plastid genomes.
- Identifies potentially missing annotations for plastid housekeeping genes
- Standardizes quadripartite structure boundaries and inverted-repeat coordinates

EXTRACTION OF DNA SEQUENCES:
- Done via module 'Extraction'
- Extraction supports numerous biologically meaningful gene categories, including protein-coding genes, tRNAs, rRNAs, introns, intergenic spacers, cis- and trans-spliced genes, overlapping and nested genes.
- Supports standardized extraction of complex trans-spliced genes such as rps12.
- Identifies pseudogenes and redundant genes.
- Reports potentially problematic duplicated entries in 'warning.txt'.
- Reports invalid or problematic codons in 'bad_codons.txt'.

ACCOUNTING FOR GENE DUPLICATION (E.G., IRs):
- Cutomized for plastome IR duplicates
- Removes redundant duplicated gene sequences generated by plastome inverted repeats.
- Removes entries containing duplicated gene names and identical sequences.

ALIGNMENT OF DNA SEQUENCES:
- Done via module 'Alignment'
- MAFFT is executed using a fixed strategy: 'mafft –localpair –maxiterate 16'.
- Alignment workflow includes both pre-alignment and post-alignment processing.
- Batch processing of multiple sequence matrices.
- Records skipped datasets and warning messages in 'warning.txt'.


ENABLES GENE ALIGNMENT BASED ON AAs:
- Performs CDS quality assessment and codon checking
- Supports translation of CDS sequences to amino-acid sequences
- Unclear if implementation of codon-aware AA-guided alignments [PLEASE CHECK THAT!]

OTHER FEATURES:
- Alignment refinement using HomBlocks, ORPA, and OGU.
- Screens molecular markers based on sequence variation.
- Gene-level visualization of annotation completeness and structural variation.
- Submission support for GenBank records.
- Partitioned Phylogenetic reconstruction functionality through integrated tools.

INPUT DATA LIMITATIONS:
- Restricts alignment to datasets containing at most 50 sequences and sequence lengths of at most 10 kb.

RUNTIME DURATION:
[INFORMATION MISSING!]

MPI IMPLEMENTATION:
- No native MPI implementation
- Computation handled through server-side task queues (RabbitMQ-based job management).
- MPI support may be present in some third-party tools (e.g., MAFFT)

MAIN RESTRICTIONS:
- Users are dependent on the availability and performance of the PlastidHub server.
- Long-term reproducibility may be affected if the web service changes or becomes unavailable.
- Users cannot freely select MAFFT algorithms or fine-tune alignment parameters.
- Restricts alignment to datasets containing at most 50 sequences and sequence lengths of at most 10 kb: "... datasets are restricted to a maximum of 50 sequences and a maximum sequence length of 10 kb ..." (see section describing the Alignment tool); thus unsuitable for large phylogenomic datasets.
